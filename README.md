# 🧩 BlocksCode - المنصة الاحترافية لتعلم تطوير الويب بصرياً

![BlocksCode Banner](https://via.placeholder.com/1000x300/4F46E5/FFFFFF?text=BlocksCode+-+Professional+Visual+IDE)

**BlocksCode** هي بيئة تطوير متكاملة (IDE) ومنصة تعليمية تفاعلية، تم بناؤها لتمكين المبتدئين من إتقان تقنيات الويب (HTML, CSS, JavaScript) عبر تجربة بصرية غامرة. تعتمد المنصة على مفهوم "البرمجة بالقطع" (Block-based Coding) مع تحويلها فورياً إلى كود احترافي مطابق للمعايير العالمية.

---

## 🚀 التطور النوعي (The Evolution)
انتقلت BlocksCode من مجرد أداة سحب وإفلات بسيطة إلى منصة إنتاجية متكاملة تضم:
- **نظام إدارة مشاريع احترافي:** حفظ وتنزيل المشاريع بصيغة JSON، وتصدير العمل النهائي كملفات ZIP جاهزة للنشر.
- **مفتش عناصر متقدم (Advanced Inspector):** لوحة تحكم في خصائص الـ CSS تحاكي أدوات المطورين في Chrome.
- **شجرة الـ DOM التفاعلية:** لوحة مخصصة للتنقل بين طبقات العناصر المعقدة بسهولة.
- **أكاديمية BlocksCode:** منهج تعليمي يضم أكثر من 30 درساً تفاعلياً يغطي أساسيات ومبادئ تطوير الواجهات.

---

## ✨ المميزات الرئيسية (Key Features)

### 💻 بيئة التطوير المرئية
- **محرك Drag & Drop ذكي:** معالجة معقدة للعناصر المتداخلة (Nesting) وإعادة الترتيب اللحظي.
- **معاينة حية (Live Preview):** عرض فوري للتغييرات داخل بيئة معزولة وآمنة (Sandboxed Iframe).
- **مفتش الـ CSS:** تعديل الألوان، المسافات (Padding/Margin)، الخطوط، والتنسيقات المتقدمة بصرياً.
- **شجرة العناصر (DOM Tree):** عرض هيكلي للمشروع يسهل الوصول للعناصر العميقة.

### 🎓 النظام التعليمي والتدريبي
- **مسارات تعلم متدرجة:** دروس تبدأ من "أهلاً بالعالم" وصولاً إلى بناء واجهات مستخدم معقدة.
- **نظام التحقق الذكي:** خوارزمية لمقارنة الكود الناتج مع الحل الصحيح لضمان دقة التعلم.
- **الاختبارات (Quizzes):** وحدات تقييم مدمجة لقياس مستوى الاستيعاب المعرفي بعد كل وحدة.
- **نظام النقاط والإنجازات:** (XP & Achievements) لتحفيز المتعلمين وتتبع تقدمهم.

### 🛠️ إدارة البيانات والتصدير
- **إدارة المشاريع:** إمكانية إنشاء مشاريع متعددة، تسميتها، والتبديل بينها.
- **الحفظ التلقائي:** مزامنة مستمرة مع `localStorage` لضمان عدم ضياع العمل.
- **التصدير الاحترافي:** تصدير الكود كملف ZIP يحتوي على (index.html, style.css, script.js) مرتبة وجاهزة للاستخدام.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

تم تطوير المنصة بالكامل باستخدام **Vanilla JavaScript**، مما يجعلها سريعة جداً وخفيفة ولا تعتمد على أي إطارات عمل ثقيلة:
- **Core:** JavaScript (ES6+), HTML5, CSS3.
- **Architecture:** State Management System, SPA Router.
- **Styling:** CSS Variables, Glassmorphism Design System.
- **Icons:** FontAwesome 6.
- **Libraries:** JSZip (لتصدير الملفات).

## 📂 هيكل المشروع (Project Structure)

```text
/BlocksCode
│
├── index.html           # المدخل الرئيسي والتطبيقات الأساسية
├── /css
│   └── style.css        # نظام التصميم (Design System) والقواعد الشاملة
└── /js
    ├── app.js           # المحرك الرئيسي وتنسيق العمليات
    ├── state.js         # إدارة حالة التطبيق المركزية
    ├── blocks.js        # تعريف قطع الكود وقوالب التوليد
    ├── projects.js      # منطق إدارة وحفظ المشاريع
    ├── lessons.js       # محتوى الدروس ومنطق التحقق
    ├── quiz.js          # نظام الاختبارات والتقييم
    ├── dom-tree.js      # لوحة الملاحة الهيكلية للمشروع
    ├── preview.js       # محرك العرض والارتباط مع الـ Iframe
    ├── dragdrop.js      # منطق السحب والإفلات المتقدم
    ├── achievements.js  # تتبع التقدم ومنح الأوسمة
    ├── export.js        # منطق تحويل المشروع إلى ZIP
    ├── router.js        # التنقل الداخلي (Home, IDE, Academy)
    ├── storage.js       # التعامل مع التخزين المحلي
    └── layout.js        # إدارة واجهة المستخدم والوضع الليلي
```

## 🏁 البدء (Getting Started)
